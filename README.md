# 福島県自治体マスター (Fukushima Municipality Master)

福島県の全59市町村名、位置、およびその土地の特徴を、クイズ形式で楽しく学べるWebアプリケーションです。

## 特徴 (Features)
- **モダンなUI/UX**: ダークモード＆グラスモーフィズムを取り入れた、リッチで直感的なデザイン。
- **2つの学習モード**:
  - **Feature Mode (特徴当てクイズ)**: 提示された特徴（特産品、名所など）から自治体を推測します。
  - **Map Mode (位置当てクイズ)**: 実際の福島県の白地図上でハイライトされた場所がどこかを当てます。
- **コレクションダッシュボード**:
  - 覚えた（正解した）市町村が実際のマップ上で緑色に塗りつぶされていく進捗可視化機能。
  - 地図上の市町村をタップすると文字がポップアップし、連動して詳細情報が確認できます。

## 技術スタック (Tech Stack)
- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+, Vanilla)
- SVG (実際のGeoJSONデータから生成した地理マップ)
※ 外部のフレームワークやライブラリ（React, Vue等）に依存しない軽量なSPA（Single Page Application）構成です。

## 使い方 (Usage)
1. リポジトリをクローンするか、ファイルをダウンロードします。
2. `index.html` をブラウザで開くだけで動作します（ローカルサーバー不要）。
3. または、GitHub Pages等のホスティングサービスにデプロイして公開することも可能です。
